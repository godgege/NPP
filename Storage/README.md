# Netch
Prebuilt binaries for Netch version 1

## Bundled v2rayN client

Run `..\prepare-v2rayn.ps1` to prepare the complete official portable client in
`v2rayN\`, or pass `-ArchivePath` to import an already downloaded ZIP. The script
verifies the version-pinned SHA256 in `v2rayN.package.json`. The resource directory
is ignored by Git and contains distribution files only; NPP launches an isolated
copy from its writable user-data directory. Do not launch this resource copy.

Upstream: https://github.com/2dust/v2rayN

License: GPLv3 (see `v2rayN.LICENSE`). Exact source revision is in the package metadata.
